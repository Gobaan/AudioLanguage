# Visual Asset Instructions

Visuals should teach meaning through scene context. Do not rely on printed text, captions, speech bubbles, or visible dialogue to explain the target phrase.

Folder rules:

- Keep shared visual production folders language-neutral.
- Only `Drafts` and `final` should exist for visual production unless a task explicitly creates another asset category.
- Do not create language-specific visual folders for the same scene.
- Frame filenames and metadata should use frame numbers starting at 1.

Frame rules:

- Each frame should make the speaker turn, gaze, gesture, and scene pressure visually clear.
- Use the same characters, setting, and camera logic across frames in one scene.
- The learner response frame should show that it is the learner's turn without showing the spoken text.
- Final/world-response frames should visibly confirm whether the learner response worked.

Prompt and regeneration rules:

- Sanitize prompts before image generation so they do not invite text, captions, subtitles, punctuation, signs, or speech bubbles.
- When regenerating, target the specific failed detail while preserving approved character identity, setting, composition, and style.
- Contact sheets should make continuity, speaker order, missing images, and reviewer notes easy to inspect.
