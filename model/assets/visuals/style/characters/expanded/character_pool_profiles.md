# Expanded Character Pool

These characters are intended to reduce phrase-to-person overfitting in dialogue visuals. Use them as interchangeable scene partners across functions, not as fixed carriers of one phrase.

Global visual rules:

- Polished clean anime/comic style matching the character-free style reference.
- No readable text, labels, captions, logos, speech bubbles, or UI.
- Reference-sheet layout: one character, plain warm background, front pose, three-quarter pose, and two small expression/gesture variations.
- Clothing should be ordinary, reusable, and culturally neutral enough for everyday public scenes.
- Preserve each character's age impression, hairstyle, body type, clothing palette, and accessories when reused.
