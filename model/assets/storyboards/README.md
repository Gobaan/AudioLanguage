# Storyboards

Storyboards describe the visual context for dialogue cards before any image or video assets are generated.

Each storyboard should connect directly to a `scene.id` in `audio_sources/dialogues.json` and describe a small visual arc for the first dialogue:

- The situation before the learner speaks.
- The learner's expected response.
- The social resolution after the response.

These files are source material for future generated images, short clips, or multi-frame card art.
